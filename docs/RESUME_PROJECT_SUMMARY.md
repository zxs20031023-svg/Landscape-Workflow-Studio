# 简历项目描述建议

下面这几版都可以直接用于简历、作品集或面试自我介绍，侧重点略有不同。

## 版本一：偏工程实现

使用 Vue 3、TypeScript、Pinia 和 Vue Router 将景观设计前期分析流程重构为可独立运行的前端工作台，完成知识库导入、场地分析、设计任务书生成、案例推荐、项目资产沉淀和本地状态持久化等模块，并将部分规则与推荐逻辑迁移到前端服务层。

## 版本二：偏产品与闭环

主导将原型式景观设计分析流程整理为前端应用，搭建“知识准备 -> 场地分析 -> 任务书生成 -> 资产沉淀”的完整工作流，支持演示模式与远程模型模式切换，提升了项目展示性、可维护性和后续扩展空间。

## 版本三：偏 AI + 前端

基于 Vue 3 重构 AI 辅助景观设计工作台，在不依赖独立后端改造的前提下，通过浏览器端知识库、规则修正、案例推荐和双模式生成链路实现完整可演示闭环，并为后续接入真实模型服务预留清晰接口边界。

## 适合面试时展开讲的点

- 为什么不做简单页面复刻，而是重构成完整前端工作流
- 如何用 Pinia 组织跨页面状态联动
- 如何在浏览器端做轻量知识库和去重检索
- 为什么要设计演示模式和远程模式两条链路
- 如何把规则能力和推荐逻辑从后端思路迁移到前端服务层
- 如何在没有后端会话的情况下做工作区状态恢复

## 可以提炼成的亮点关键词

- 前端工程化
- AI 工作流产品化
- 多页面状态联动
- 轻量知识库
- 规则驱动结果修正
- 本地持久化
- 双模式生成链路

## 一句话版本

将景观设计前期分析流程重构为一个基于 Vue 3 的可独立运行前端工作台，覆盖知识库、场地分析、任务书生成、案例推荐与资产沉淀，并支持演示模式和远程模型模式切换。
