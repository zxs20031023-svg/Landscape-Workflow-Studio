# 简历项目描述建议

## 版本一：偏工程实现

独立使用 Vue 3 + TypeScript 重构景观设计智能工作台，将原有 Streamlit 原型升级为完整前端工程，完成知识库管理、场地分析、设计任务书、案例推荐、在线案例导入与资产中心等模块，并迁移规则引擎与推荐逻辑到前端服务层。

## 版本二：偏产品能力

主导将景观设计前期分析原型产品前端化与工程化，设计了知识库、案例库、任务书与场地分析闭环，支持演示模式与联网智能模式切换，提升项目可展示性、可维护性和交互完成度。

## 版本三：偏 AI + 前端

基于 Vue 3 重构 AI 辅助景观设计工作台，将规范检索、规则修正、案例推荐和结构化结果展示整合进统一状态流；在无后端改造前提下，通过浏览器端知识库与双模式生成方案实现完整可演示闭环。

## 面试可重点讲的点

- 为什么要做独立前端重构，而不是继续维护 Streamlit
- 如何把 Python 规则与推荐逻辑迁移到 TypeScript
- 为什么前端版要引入演示模式
- 如何处理知识库、案例选择和任务书之间的跨页面状态联动
- 如何在“不能改原项目”的限制下保证新项目独立可运行
