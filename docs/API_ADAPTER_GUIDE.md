# 远程模型适配说明

## 1. 当前实现方式

前端通过 `fetch` 直接请求：

`{Base URL}/chat/completions`

适配常见的 OpenAI Compatible 接口。

## 2. 前提条件

智能联网模式要成功，需要服务满足：

- 允许浏览器跨域请求
- 支持 `Authorization: Bearer ...`
- 支持 `chat/completions`
- 最好支持 `response_format: { type: "json_object" }`

## 3. 可能遇到的问题

### CORS 报错

表现：

- 浏览器控制台提示跨域失败

原因：

- 目标模型服务不允许前端直接访问

处理方式：

- 使用演示模式
- 或在后续版本增加中间层代理服务

### 返回内容不是严格 JSON

表现：

- 远程模式调用成功，但解析失败

当前策略：

- 自动回退到演示模式结果

## 4. 后续可扩展方向

- 接入文件上传 API
- 接入真实在线搜索服务
