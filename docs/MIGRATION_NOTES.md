# 迁移说明

## 1. 原项目来源

原项目是基于：

- `Streamlit`
- `LangChain`
- `OpenAI Compatible API`
- `ChromaDB`

构建的景观设计前期分析工作流。

## 2. 本次迁移范围

### 保留

- 规范知识库导入
- 任务书生成
- 场地分析
- 本地案例推荐
- 在线案例检索与导入
- 项目历史记录

### 重构

- 页面布局
- 交互方式
- 状态管理
- 规则引擎实现语言
- 案例推荐实现语言
- 产物展示方式

## 3. 从 Python 到 TypeScript 的迁移点

### 已迁移

- 规则引擎
- 推荐引擎
- 轻量知识库检索
- 历史资产管理
- 在线案例导入逻辑

### 未 1:1 迁移

- Python 的 Chroma 向量数据库
- LangChain 回调体系
- Streamlit 文件与 session state 模型

## 4. 为什么不是完全等价

因为“完整前端项目”和“原后端逻辑完全保留”在没有改动源项目的前提下，本身就存在技术边界。

本次方案选择了更适合作品集的做法：

- 保留核心业务形态
- 前端独立运行
- 工程结构更清晰
- 结果页更适合展示

## 5. 新增优化

- 演示模式
- 项目资产中心
- 图表化总览
- 更完整的文档体系
- 更适合前端岗位展示的页面语言
