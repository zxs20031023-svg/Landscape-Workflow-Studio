# UI 与技术方案调研

本次重写参考了以下官方文档与生态方案：

- Vue 3 官方文档：组件化、组合式 API、单文件组件与工程化建议
- Vue Router 官方文档：路由分视图结构
- Pinia 官方文档：集中式状态管理
- Element Plus 官方文档：表单、上传、表格、时间线等后台类组件
- Apache ECharts / vue-echarts：图表化总览与成熟度表达

## 设计方向

为了避免做成常见的浅色后台模板，这个项目选择了更贴合景观主题的视觉方向：

- 沙色与橄榄绿的自然语义色板
- Serif 标题 + Sans 正文字体组合
- 玻璃拟态与柔和渐变背景
- 结果页强调“可讲述性”，而不是只展示原始 JSON

## 页面策略

- 总览页：讲产品闭环和工程完成度
- 知识库页：讲文件处理与前端轻量检索
- 任务书页：讲规则、依据、结构化输出
- 场地分析页：讲推荐链路与状态同步
- 资产中心：讲结果沉淀与项目资产化
